# Git Commit Message Tags

- `[frontend]`: Fetch, prediction, decode, or frontend integration changes.
- `[backend]`: Rename, ROB, execution, commit, or CSR changes.
- `[memory]`: LSU, cache, PMA, MMIO, or AXI data-path changes.
- `[core]`: Top-level core interfaces or cross-subsystem integration changes.
- `[verification]`: Tests, differential harnesses, formal, coverage, or reports.
- `[docs]`: Documentation-only changes.
- `[build]`: Build, toolchain, or automation changes.
- `[release]`: Milestone or release metadata changes.

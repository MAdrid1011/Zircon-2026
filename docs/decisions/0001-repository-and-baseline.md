# ADR-0001：新父仓与既有子仓长期分支

状态：Accepted
日期：2026-08-31

## 决策

Zircon-2026 使用新的公开父仓和全新历史。RV-Software、ZirconSim 继续使用既有仓库，各自以 `zircon-2026` 长期分支演进；父仓始终固定子模块 commit。

## 原因

父仓新历史避免将 Zircon-2024 目录组织和未清理实验状态当作新架构事实。复用子仓保留已有软件与仿真工具的提交历史。固定 gitlink 使一次硬件、软件和仿真组合可以复现。

## 约束

- 2024 用户工作区不执行 reset、checkout 或自动提交。
- 旧工作区未提交改动必须先审计，再以独立 PR 移植。
- 父仓更新子模块时必须链接子仓验证证据。

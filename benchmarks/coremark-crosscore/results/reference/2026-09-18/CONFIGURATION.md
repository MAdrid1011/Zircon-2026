# 参考配置

以下架构数据来自参考运行所使用的生成配置或默认配置；自动校验覆盖 CoreMark 分数与 CRC。
主机工具为 Clang/LLVM 23.1.1、Verilator 5.052、Mill 0.12.15、sbt 1.5.5 和
Temurin JDK 11.0.32.1。源码版本见 `configs/revisions.lock`。
